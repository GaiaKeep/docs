    Status at a glance¶

    Every component is labelled Proven, Built, Designed, Proposed or Open; the home page defines them. The base is release 1.3 (2026-10-01: GaiaKeep/gfs 1.3 at 8461e1a, CI green on 2,188 core tests). Rows changed since carry their date: erasure coding became the default on 2026-10-14, and the live tier and core stability sections are as of 2026-10-28, on the development branch, not yet merged or released. Details are in Test results and Benchmarks.

    Release 1.3: the durable storage core, validated on the HPC cluster

    The secured build passes the live fabric check 88/88 on the HPC cluster. That build has signed requests, strict node-key pinning and sealed keys. An 8 GB ingest at three copies runs at 146 MB/s and reads back at 289 MB/s, byte-identical. No request takes more than 20 s. A de-identified DICOM re-upload sends 0.79 % of its bytes.

    Continuous integration¶

    CI runs on the HPC cluster as batch jobs, never on GitHub Actions (owner decision 2026-10-02): every head of main and 1.3 is tested and the result posted as a commit status. Since 2026-10-25 main is the development branch and 1.3 moves only by fast-forward to a main commit whose CI passed. CI on the live tier's merged tree (its first four milestones) ran green with 3,052 tests on 2026-10-28. See Running the tests.
